# 源码阅读实验

实验只验证一个假设，不追求完整应用。每个实验都必须有可执行命令和预期结果。

## 计划中的实验

| 周次 | 实验 | 假设 | 最小验证 |
|---|---|---|---|
| W5 | Gson 自定义 `TypeAdapter` | 自定义适配器优先级高于默认反射适配器 | 同一 JSON 在默认与自定义配置下产生不同字段值 |
| W8 | Micrograd 标量计算图 | 链式法则能通过反向传播逐节点累积 | 手算梯度与 `backward()` 结果一致 |
| W9 | OpenAI SDK Mock 传输 | 不调用真实 API 也能验证请求构造和流式解析 | 使用假 transport 记录请求与 response events |
| W10 | LangGraph 三节点状态图 | 状态在节点之间按 reducer 合并 | 输入一个计数，输出经过三节点后的确定状态 |

## 实验规则

- 先写预测，再运行命令。
- 记录完整命令、预期、实际结果和风险。
- 失败实验保存错误与修复，不删除证据。
- 不提交 `.venv/`、`target/`、`build/`、缓存、密钥或上游源码。
- 关键实现由学习者完成；脚手架可以预置，关键函数保留明确 TODO 和验收测试。
