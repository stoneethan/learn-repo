## 每天/每周铁律

1. **每天必须打卡**：打开 tracker.html 点"今天打卡"，保住连续天数（断 1 天可补，绝不断 2 天）。
2. **每天必须写代码**：刷题或项目二选一，18 个月不断档。
3. **每周至少 1 个产出物**：commit / 博客 / 实验记录 / 面经笔记。
4. **每周日 21:00**：30 分钟复盘，勾选本周清单，填 `02-周复盘模板.md`。
5. **每月第 4 周为冲刺周**：任务量 +50%。
6. **连续 2 周无产出物** → 触发降载：砍非核心任务，只保项目主线（见 `09-完成保障机制.md`）。
7. **卡住先问 AI**（Copilot/Codex），再查资料，不要硬扛到放弃。
